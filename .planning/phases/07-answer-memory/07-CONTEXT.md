# Phase 7: Answer Memory - Context
Owner said "build everything" and accepted Nehemiah's recommendations (to confirm at acceptance):
- Only first questions of a conversation; match = same language + same words (order, punctuation and Hebrew prefixes ignored)
- Any change to the knowledge base (upload) empties the memory
- "Didn't help" on a remembered answer removes it
- Remembered answers keep 30 days; tagged "from memory" on screen
- Repeat of a question that was a gap still counts on that gap, and in the stats, without a Claude call
- Follow-ups after a remembered answer work (conversation built from the stored answer)

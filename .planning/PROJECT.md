# Learning Knowledge Center

## What This Is
A learning knowledge center for a 19-person team working on a water-sector product.
Team members ask questions and get full answers composed by Claude from the company's
procedures, documents and customer answers, with the source document shown on the side.
Unanswered questions are logged; every 3 days a gap report goes to the responsible staff,
who upload a matching document that enters the knowledge base directly.

## Core Value
Accurate answers, grounded only in the company's own knowledge. Never invent.

## Constraints
- React frontend; DB layer must be swappable (company uses several DBs)
- AI model: Claude, behind a swappable adapter
- v1 uses mock (fake) data about a water product
- Final deployment: internal company system behind VPN
- UI language: Hebrew (RTL)

## Out of Scope (v1) - saved for later
- Microsoft Teams integration
- Ingesting documents from all internal network locations

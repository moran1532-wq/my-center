# מרכז ידע לומד

מרכז ידע לצוות: שואלים שאלה ומקבלים תשובה מלאה מתוך הנהלים והמסמכים, עם המקור בצד.
שאלה בלי תשובה הופכת לפער. כל 3 ימים נשלח לאחראי הידע דוח פערים. אחראי מעלה מסמך, הפער נסגר, ובפעם הבאה יש תשובה.

## מה יש במערכת
| לשונית | מה עושים בה | מי |
|---|---|---|
| שאלות | שאלה ← תשובה מלאה מ-Claude, מקורות בצד, שאלות המשך, "התשובה לא עזרה", העתקה | כולם |
| עיון במאגר | כל המסמכים, סינון וחיפוש, "הוספת מסמך", "הסרה מהמאגר" (לארכיון, עם החזרה) | כולם / הוספה והסרה: אחראי ידע |
| פערי ידע | פערים פתוחים ונסגרו, "העלאת מסמך", "לא פער" | כולם / פעולות: אחראי ידע |
| דוחות | דוחות פערים, הפקה עכשיו, רשימת אחראי ידע | אחראי ידע |

עברית ואנגלית בכל המערכת, כולל התוכן.

## הפעלה במחשב (פיתוח)
```
npm run setup   # פעם אחת
npm run dev     # שרת + מסך, http://localhost:5173
```
בפיתוח כולם "אחראי ידע". כדי שהשאלות יעבדו צריך `ANTHROPIC_API_KEY` (ראו `server/.env.example`).

## התקנה ברשת הפנימית
1. **שרת:** Node 22. `cd server && npm ci`, ואז `npx tsx src/index.ts` (או שירות/קונטיינר שמריץ את זה).
2. **מסך:** `cd client && npm ci && npm run build` - התיקייה `client/dist` היא אתר סטטי. מגישים אותה, ואת `/api` מעבירים לשרת.
3. **הגדרות:** מעתיקים את `server/.env.example` וממלאים. חובה: `AUTH_MODE=proxy` + `AUTH_PROXY_SECRET`, ו-`ANTHROPIC_API_KEY`.
4. **כניסה:** המערכת הפנימית שלכם (שכבר מחברת משתמשים) עומדת לפני השרת ומוסיפה לכל בקשה:
   `X-User-Email`, `X-User-Role` (`owner` לאחראי ידע, אחרת חבר צוות) ו-`X-Auth-Secret`.
   בלי הכותרות האלה השרת לא עונה. אסור לחשוף את השרת ישירות, רק דרך המערכת הפנימית.
5. **מייל:** פרטי שרת המייל של החברה ב-`SMTP_*`. בלעדיהם הדוח נשמר ולא נשלח.
6. **גיבוי:** כל הנתונים בתיקייה `DATA_DIR` (פערים, מסמכים שהועלו, דוחות, נמענים). מגבים אותה.

## מבנה
- `server/` - השרת (Express). חלקים מוחלפים: מאגר ידע (`KnowledgeStore`), פערים (`GapStore`), מייל (`Mailer`), כניסה (`auth.ts`) - כדי לחבר את מסדי הנתונים והמערכות שלכם.
- `server/data/knowledge.json` - 12 פריטי ידע **לדוגמה בלבד**. מסמכים אמיתיים נשמרים בנפרד (`uploaded.json`).
- `client/` - המסך (React). `npm run build:demo` בונה גרסת ניסיון שעובדת בלי שרת.

## בדיקות
`cd server && npm test` - 64 בדיקות. בכל העלאה ל-GitHub רצות אוטומטית: הבדיקות, בניית המסך, סריקת תלויות וחיפוש סודות.

- להחליף את 12 פריטי הדוגמה בידע אמיתי (או להעלות מסמכים דרך המערכת).
- לבדוק פעם אחת עם מפתח Claude אמיתי ושרת מייל אמיתי ברשת שלכם.
- שלב הבא: חיבור לטימס, וקליטת מסמכים מכל הרשת הפנימית.

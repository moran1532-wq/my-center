# מרכז ידע לומד

מרכז ידע לצוות: שואלים שאלה, מקבלים תשובה מלאה מתוך הנהלים והמסמכים, עם מסמך המקור בצד.

## הפעלה
```
npm run setup   # התקנה, פעם אחת
npm run dev     # מפעיל שרת + מסך
```
המסך נפתח בכתובת http://localhost:5173

## מבנה
- `server/` - השרת. האחסון עובר דרך `KnowledgeStore`, כך שאפשר לחבר כל מסד נתונים.
- `server/data/knowledge.json` - הידע לדוגמה (מדומה בלבד).
- `client/` - המסך (React), עברית ואנגלית.

## הגדרות
- `ALLOWED_ORIGINS` - כתובות שמורשות לפנות לשרת מהדפדפן (מופרדות בפסיק). לא נדרש בפיתוח.
- `PORT` - פורט השרת (ברירת מחדל 3001).
